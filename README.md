# 🎓 JEE Advanced 2026 Registration Form

A fully functional, front-end registration form for the Joint Entrance Examination (JEE) Advanced 2026. This form simulates the official candidate registration process with comprehensive validation and a professional user interface.


## ✨ Features

### 📋 Complete Registration Sections
- **Personal Details** - Name, Date of Birth, Parents' names, Gender, Category
- **Contact Information** - Email, Mobile number, Permanent address
- **Academic Qualifications** - Class 10th & 12th board details with passing years
- **Exam Preferences** - Test center zone and question paper language
- **Declaration** - Terms acceptance with legal acknowledgment

### ✅ Advanced Validation
- Age verification (18-26 years as per JEE criteria)
- 10-digit mobile number validation (starting with 6-9)
- Email format validation
- Mandatory subject selection (Physics, Chemistry, Mathematics)
- Real-time error clearing on input
- Visual error indicators (red borders)

### 🎨 Professional UI/UX
- Clean, exam-oriented color scheme (blue & gold theme)
- Responsive design (mobile, tablet, desktop)
- Section-wise form organization with numbered sections
- Field hints for better user guidance
- Success/Error feedback messages
- Auto-generated registration number on successful submission

### 🔧 Technical Features
- Pure HTML5, CSS3, and Vanilla JavaScript
- No external dependencies or frameworks
- Cross-browser compatible
- Form reset functionality
- Live input validation
- Keyboard accessible
